# Study rhythm and routines

This guide defines a repeatable study rhythm for an SAE trimester. It is a default operating system, not a rigid timetable: keep the review points consistent, then adjust individual study blocks around classes, work, health, and deadlines.

## Sources of truth

Use one place for each kind of information so that plans do not drift:

| Information | Source of truth |
| --- | --- |
| Classes, appointments, and hard deadlines | Calendar |
| Assignments, milestones, and next actions | Linear |
| Class notes, research, and reference material | Study notes |
| Submitted work and project files | Course or project folder |

When new information arrives, capture it in the correct source of truth during the next daily shutdown. Do not rely on chat messages, browser tabs, or memory as reminders.

## Trimester setup

Complete this routine before teaching starts and revisit it whenever a unit outline changes:

1. Add every class, assessment deadline, and known academic event to the calendar.
2. Create a workspace for each unit with its outline, assessment briefs, notes, resources, and project files.
3. Create one Linear issue for each assessment and add its due date.
4. Break each assessment into milestones: understand the brief, research, plan, draft or build, get feedback, revise, quality-check, and submit.
5. Schedule the first action and a target date for each milestone.
6. Reserve recurring weekly focus blocks, review time, and buffer time.
7. Confirm that every assessment has a visible deadline, current status, and next action.

Aim to finish work at least 24 hours before the official deadline. Keep that final day as submission and recovery buffer rather than planned production time.

## Weekly rhythm

### Weekly review — 30 to 45 minutes

Run the review at the same time each week, preferably before the first study block:

1. Check the calendar for the next two weeks, including classes, deadlines, and personal commitments.
2. Review every active unit and assessment in Linear.
3. Capture any missing tasks, notes, or dates.
4. Choose up to three outcomes that would make the week successful.
5. Break those outcomes into concrete next actions that fit within one study block.
6. Place focus blocks on the calendar, starting with the highest-risk or nearest-due work.
7. Leave at least one block uncommitted for spillover, illness, or unexpected work.
8. Archive or defer work that is no longer relevant.

An outcome describes a finished result, such as “first mix ready for feedback.” A next action describes the next visible step, such as “export and label the current mix.”

### Suggested week

| When | Routine | Purpose |
| --- | --- | --- |
| Start of week | Weekly review | Set priorities and reserve time |
| Before each class | 10-minute preview | Reopen the last notes and identify questions |
| After each class | 15-minute capture | Process notes and create next actions |
| Most weekdays | One or two focus blocks | Progress the week's priority outcomes |
| Midweek | 10-minute checkpoint | Re-plan work that has slipped or changed |
| End of week | 20-minute closeout | Record progress and prepare the next review |

## Daily rhythm

### Start — 5 to 10 minutes

- Check today's calendar and current Linear tasks.
- Select one must-do outcome and, if capacity allows, one secondary outcome.
- Define the first physical action before starting a focus block.
- Clear unrelated tabs, notifications, and equipment from the workspace.

### Focus block — 50 minutes

1. Work on one named next action.
2. Capture distractions or unrelated ideas without switching tasks.
3. Stop after 50 minutes for a 10-minute break away from the workstation.
4. After two blocks, take a longer break and reassess capacity.

Use shorter 25-minute blocks on low-energy days. Starting a reduced block keeps the rhythm intact and is better than abandoning the day.

### Shutdown — 10 minutes

- Record what changed and where the work stopped.
- Write the next action so the project is easy to resume.
- Update the task status and any changed dates in Linear.
- File new notes and project assets in their source-of-truth location.
- Check tomorrow's calendar and prepare anything needed for the first block.

## Class routine

### Before class

- Review the previous class summary and outstanding questions.
- Open a note with the date, topic, and learning outcomes.
- Prepare required software, files, and equipment.

### During class

- Capture decisions, demonstrations, terminology, and questions rather than a transcript.
- Mark unclear points for follow-up.
- Record any new deadline or assessment requirement immediately.

### After class

- Write a short summary in your own words.
- Turn follow-ups and assessment work into Linear tasks.
- Link or file handouts, recordings, and references.
- Schedule the next action if it cannot be completed immediately.

Process class notes within 24 hours while the context is still fresh.

## Assessment routine

Move each assessment through the same stages:

1. **Clarify:** annotate the brief, rubric, deliverables, constraints, and submission method.
2. **Plan:** define milestones, dependencies, risks, and the internal completion date.
3. **Produce:** create the smallest reviewable version early, then iterate.
4. **Review:** compare the work with every rubric criterion and seek feedback while there is time to act on it.
5. **Finish:** complete technical checks, naming, exports, references, and backups.
6. **Submit:** upload early, verify the submitted files, and save the receipt or confirmation.
7. **Reflect:** note what worked, what created friction, and one change for the next assessment.

Review progress at least weekly. In the final two weeks before a deadline, review it during each daily shutdown.

## Minimum viable study day

When time or energy is limited, preserve continuity with this reduced routine:

1. Check the next deadline and choose one useful action.
2. Complete one 25-minute focus block.
3. Record progress and the next action.
4. Re-plan missed work during the next daily or weekly review.

Do not silently carry overdue work forward. Either schedule it, reduce its scope, ask for help, or explicitly defer it.

## Escalation and recovery

Escalate early when a deadline is at risk:

- If a planned block is missed, reschedule or reduce the work during the next shutdown.
- If the same task slips twice, identify the blocker and split the task into a smaller action.
- If the internal completion date is at risk, use the reserved buffer and seek feedback or support.
- If the official deadline is at risk, contact the lecturer or relevant support service as soon as possible and record the agreed next step.

After illness, travel, or an overloaded week, restart with a weekly review. Reconfirm deadlines, select the smallest current priorities, and rebuild the calendar from today rather than trying to recreate the missed plan.

## End-of-trimester review

At the end of the trimester:

- Confirm that submissions, feedback, and final project files are saved.
- Archive completed tasks and unit materials without deleting useful references.
- Review assessment reflections and identify patterns in planning, energy, and feedback.
- Keep the routines that helped, change one or two sources of friction, and carry those adjustments into the next trimester setup.
